# Digital Lab website

Digital Lab, The Hong Kong Polytechnic University (working name; formerly EIES Lab — Laboratory for Embodied Intelligence in Energy Systems).

Bilingual (EN `/`, ZH `/zh/`) lab site built on [HugoBlox academic-cv](https://github.com/HugoBlox/hugo-theme-academic-cv) (MIT). Upstream README: `README.hugoblox.md`.

## Run locally

Requires Hugo 0.162 extended, Go, Node 22 and pnpm 10.

    pnpm install
    hugo server            # http://localhost:1313
    pnpm build             # production build into public/ (scenes + Hugo + search index)

## Homepage 3D scene

The homepage hero (`block: hero-scene`) plays a live 3D scene from `scenes/` (three.js, own Vite package in the pnpm workspace) in an iframe, over a poster image. Code and data are deployed on the same server: site at `/`, scene at `/scenes/`, data at `/scene-data/<place>/` (not in git, ~1.6 GB).

    pnpm install
    pnpm scenes:dev        # http://localhost:5180/ (serves ../data as /scene-data/)
    hugo server            # hero loads the scene from :5180 in development

Structure, parameters, deployment and how to add a research theme: `scenes/README.md`.

## Add a member (no page file needed)

1. `data/authors/<slug>.yaml` — English profile; copy an existing member such as `tan-hongjun.yaml`. Set `user_groups` to one of the groups in `content/team/_index.md`.
2. `data/zh/authors/<slug>.yaml` — Chinese overrides only (group name must match `content/team/_index.zh.md`).
3. Avatar: `assets/media/authors/<slug>.jpg` (square).

The personal page `/team/<slug>/` is generated by `content/team/_content.gotmpl`; papers listing `<slug>` in `authors:` appear there automatically.

## Add a paper / news

- Paper: `content/publications/<name>/index.md` (+ `index.zh.md`). `featured: true` shows it on the homepage.
- News: `content/news/<name>/index.md` (+ `index.zh.md`).

## Look and feel

- Monochrome system (black / white / greys, pill buttons, 12px cards, Inter) in the `HOMEPAGE — monochrome system` block of `assets/css/custom.css`; inner pages still use the earlier site-wide rules above it.
- Homepage blocks: `hero-scene` (3D scene hero), `loop-diagram` (animated closed loop, content in `data/loop.yaml`). Footer: `layouts/_partials/site_footer.html` + `data/site_footer.yaml`.
- Logo: `assets/media/logo.png` (navbar, footer) and `assets/media/icon.png` (favicon) are the PolyU emblem. `static/media/eies-framework.jpg` is the source framework figure the loop diagram is based on.

## Local overrides of theme files

- `layouts/_partials/functions/build_links.html` — fixes a nil-map crash on Hugo 0.162.
- `layouts/_partials/hbx/blocks/team-showcase/block.html` — team cards link to `/team/<slug>/` per language.
- `layouts/_partials/hbx/blocks/markdown/block.html` — wide, left-aligned markdown block with `eyebrow`/`subtitle` and `design.layout: split`.
- New blocks: `hero-scene` (+ `assets/js/hero-scene.js`), `loop-diagram` (+ `assets/js/loop-diagram.js`), `member-profile`.

Known issue: `hugo server` can panic (`Shift: unknown type ... "/authors"`) on live reload after edits. Run `scripts/serve.sh` instead of `hugo server`: it restarts automatically. Full builds are unaffected.
