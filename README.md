# EIES Lab website

Laboratory for Embodied Intelligence in Energy Systems (能源具身智能实验室).

Bilingual (EN `/`, ZH `/zh/`) lab site built on [HugoBlox academic-cv](https://github.com/HugoBlox/hugo-theme-academic-cv) (MIT). Upstream README: `README.hugoblox.md`.

## Run locally

    export PATH=$HOME/.local/bin:$HOME/.local/go/bin:$PATH   # hugo 0.162 extended + go
    hugo server            # http://localhost:1313

## Add a member (no page file needed)

1. `data/authors/<slug>.yaml` — English profile; copy an existing member such as `tan-hongjun.yaml`. Set `user_groups` to one of the groups in `content/team/_index.md`.
2. `data/zh/authors/<slug>.yaml` — Chinese overrides only (group name must match `content/team/_index.zh.md`).
3. Avatar: `assets/media/authors/<slug>.jpg` (square).

The personal page `/team/<slug>/` is generated by `content/team/_content.gotmpl`; papers listing `<slug>` in `authors:` appear there automatically.

## Add a paper / news

- Paper: `content/publications/<name>/index.md` (+ `index.zh.md`). `featured: true` shows it on the homepage.
- News: `content/news/<name>/index.md` (+ `index.zh.md`).

## Look and feel

- Font pack `modern` (Inter) + neutral `zinc` in `config/_default/params.yaml`.
- `assets/css/custom.css` — hugo.chat-like typography with the logo palette (navy/blue/green/orange/yellow), left-aligned sections on one shared left edge.
- Logo: source `../site/logo2.png`; `assets/media/logo.png` + `icon.png` (navbar, favicon) and `static/media/emblem.png` (homepage hero) are the cropped emblem.
- Homepage keeps Hero + Mission + Approach as the narrative; full thrust text and validation pathway live on `/research/`.

## Local overrides of theme files

- `layouts/_partials/functions/build_links.html` — fixes a nil-map crash on Hugo 0.162.
- `layouts/_partials/hbx/blocks/team-showcase/block.html` — team cards link to `/team/<slug>/` per language.
- `layouts/_partials/hbx/blocks/markdown/block.html` — wide, left-aligned markdown block with `eyebrow`/`subtitle` and `design.layout: split`.

Known issue: `hugo server` can panic (`Shift: unknown type ... "/authors"`) on live reload after edits. Run `scripts/serve.sh` instead of `hugo server`: it restarts automatically. Full builds are unaffected.
